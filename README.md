## Contenu

Rapport d'optimisation opérationnelle couvrant quatre problèmes de RO :

| Problème | Méthode | Résultat |
|---|---|---|
| Plus courts chemins | Algorithme de Dijkstra | Client A : 10 km optimal |

| Ordonnancement production | PERT / Gantt | 158 min, 7 tâches critiques |
| Maximisation marge | Simplexe (PL) | 690 €/jour |
